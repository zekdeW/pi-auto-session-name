# pi-auto-session-name

[pi coding agent](https://pi.dev) 扩展：**自动为会话命名，且名字是整个对话不同阶段「主题集合」**——随着对话展开，新主题会追加进标题，而不是被最新话题覆盖。

例如一个先聊算法、再聊做菜的会话，名字会演变为：

```
Python快速排序函数… / 红烧肉的做法 / Mac查看端口占用进程
```

名字显示在 `pi -r` / `/resume` 的会话列表里，多会话一目了然。

## 功能特性

- **主题集合式命名**：标题 = 各阶段主题按出现顺序拼接（最多 4 个，超出时合并/舍弃最旧）
- **首轮自动命名**：第一次对话结束后生成第一个主题（≤12 字）
- **实时追加**：之后每新增 N 条用户消息（默认 3）复查一次：主题没变保持不变；出现新主题追加；相近主题合并
- **手动命名保护**：用 `/name` 手动设置的名字不会被覆盖（通过会话内 custom entry 标记区分自动/手动）
- **零打扰**：命名失败静默忽略，不影响正常对话；每次复查都是一次极小的模型调用

## 安装

```bash
pi install git:github.com/zekdeW/pi-auto-session-name@v1.0.0
```

或先试用（不落盘，仅本次运行生效）：

```bash
pi -e git:github.com/zekdeW/pi-auto-session-name
```

## 配置

| 环境变量 | 默认 | 说明 |
|---|---|---|
| `PI_AUTO_NAME_EVERY` | `3` | 每新增多少条用户消息，复查一次主题列表 |

```bash
# 例：每条消息后都复查（最"实时"）
PI_AUTO_NAME_EVERY=1 pi
```

## 工作原理

1. 监听 `agent_end` 事件，首轮结束后取「用户提问 + 助手回复」（各截取 800 字符）让当前模型生成第一个主题，经 `pi.setSessionName()` 写入会话
2. 之后周期性发起一次极小的「主题列表维护」请求（当前列表 + 最早消息 + 最近几条用户消息）：主题未变则保持、新主题则追加、相近主题则合并，名字为各主题用 ` / ` 拼接
3. 每次自动命名都会向会话写入 `auto-session-name` 标记（含主题数组，兼容 v1.0 单标题标记），用于和手动 `/name` 区分；检测到手动命名后，该会话永久停止自动改名

> 命名使用你**当前选中的模型**，每次复查入参几百字符、出参最多 4 行，成本可忽略。
